\# 🏨 Corporate Hotel Reservation Attrition Analysis



\## 🎯 Project Overview \& Objective

This data analytics initiative targets revenue leaks driven by cancellation patterns under the \*\*IBM SkillsBuild Academic Internship\*\*. Processing \*\*118,732 customer booking entries\*\*, this utility evaluates predictive risk buckets to deliver direct mitigation workflows for hospitality executives.



\## 📊 Strategic Key Performance Indicators (KPIs)

\- \*\*Total Validated Orders Evaluated:\*\* 118,732 records

\- \*\*Base Customer Cancellation Count:\*\* 44,142 records

\- \*\*Global Portfolio Cancellation Rate:\*\* 37.18%

\- \*\*Mean Portfolio Revenue per Available Room (ADR):\*\* \\$102.13



\## 📦 Dataset Resource Link

\- \*\*Dataset Resource Hosting:\*\* \[Kaggle Hotel Booking Demand Repository](https://kaggle.com)



\## 🛠️ Core Technologies Used

\- \*\*Language Stack:\*\* Python 3

\- \*\*Data Engineering Module:\*\* Pandas, Numpy

\- \*\*Visualization Component:\*\* Plotly Engine (Interactive dark mode web display standard)
